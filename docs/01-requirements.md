## 1. 背景与目标

### 1.1 背景
金色传说（GoldLegend）是一套运行在 MT5 上的 XAUUSD 双向网格策略 EA：即时/指标首单 → 逆势递增步长加仓 → 抛物线「见好就收」整组止盈（含分层移动锁利）→ 账户级总浮亏触线净额锁仓冻结。目前每个账户都需要一个 MT5 终端和一张图表，人工干预依赖图表快捷菜单，告警依赖 MT5 推送。

Exness 已开放官方 Trader API（REST + WebSocket，Ed25519 请求签名，异步成交回执）。本项目用 Rust 将 EA 的全部策略逻辑迁移为服务端守护进程，直接通过 Trader API 交易，并提供 Web / Android 控制台。

### 1.2 目标
- G1 **策略等价**：Rust 内核在相同行情输入下与 MQL5 EA 产生相同的开仓 / 加仓 / 止盈 / 锁仓决策（允许因成交机制差异产生的价格级误差，不允许规则级差异）。
- G2 **多账户**：一个部署实例托管多个 Exness 账户，账户之间策略参数、状态、凭证、告警完全隔离。
- G3 **多端控制台**：Web 端（React + Ant Design）先行；Android 端复用同一套后端 API。
- G4 **可观测、可恢复**：所有决策与成交留痕；进程重启后依据 Exness 快照与本地台账自动对账恢复，不丢锁仓/暂停状态。
- G5 **可回放**：策略内核与 IO 解耦，支持用历史 Tick / 蜡烛回放验证。

### 1.3 非目标（本期不做）
- 不做策略优化或新增规则；不做参数寻优器。
- **单品种**：仅 Exness 黄金 `XAUUSD`。不同账户类型的后缀变体（`XAUUSDm`、`XAUUSDc`）视为同一品种，由预检从账户可用品种列表自动匹配，不提供品种选择。
- 不做跟单、不做资金划转、不做账户开户流程。
- 不做商业分发形态（参数锁定构建、授权到期、日志抹除）：所有客户账户都运行在我方服务器上，权限控制由多用户 RBAC 承担。
- 不替代 MT5 版 EA；两者并行存在，策略改动需双向同步。

## 2. 术语

| 术语 | 含义 |
| --- | --- |
| 点（point / 点差单位） | 策略口径的 1 点 = 0.01 美元报价距离（`USD_PER_POINT`），与 Exness `point_digits` 推导的最小报价增量不同（3 位报价时 1 策略点 = 10 个报价 point） |
| 篮子（Basket） | 同一账户同一方向（多 / 空）的全部网格持仓集合 |
| 层（Layer） | 篮子内按开仓顺序的编号，首单为第 0 层 |
| 锁仓腿 | 账户级总浮亏触线后按净敞口打出的反向持仓（EA 注释 `GL_NET_HEDGE`） |
| 冻结 | 锁仓状态机处于 ARMING / LOCKED，停止一切常规网格动作 |
| 账户运行器（AccountRunner） | 守护进程内托管单个 Exness 账户的独立任务 |
| 台账（Ledger） | 本地持久化的「持仓归属」记录：position_id → 账户、方向、角色（网格 / 锁仓）、层号 |
| 外部持仓（Foreign Position） | Exness 账户上存在、但台账中无记录的持仓（人工在终端开的单） |

## 3. 用户与角色

| 角色 | 说明 | 权限 |
| --- | --- | --- |
| 管理员（admin） | 部署与运维人员 | 全部账户 CRUD、启停、参数、用户管理、系统配置 |
| 交易员（trader） | 账户持有人或受托操盘人 | 仅被授权账户：查看、手动操作（锁仓 / 平仓 / 暂停）、修改策略参数（可被管理员禁用） |
| 只读（viewer） | 观察者 | 仅被授权账户的查看权限 |

一个用户可被授权多个账户；一个账户可授权多个用户。

### 4.2 策略引擎（STR）
策略规则以 `02-strategy-spec.md` 为唯一规范，此处只列需求级条目。

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-STR-01 | 可配置参数：`initial_lot`、`grid_step`、`grid_step_add`、`grid_step_sec`、`lot_mult`、`tp_distance_usd`、`lock_trigger_usd`；篮子为空时直接开首单；其余为内部常量（`deviation=20`、`emergency_deviation=300`、`max_spread_usd=0.50`、`news_pre=60`、`news_post=180` 等） | P0 |
| FR-STR-02 | 启动时按 `lock_trigger_usd` 自动推导单边最大层数 `max_grid_orders` 与极限抗波幅 `max_defensive_usd`，算法与 `CGridMath` 等价 | P0 |
| FR-STR-03 | 对应方向篮子为空且首单门禁通过时，立即开仓；不使用技术指标或入场信号 | P0 |
| FR-STR-04 | 逆势加仓：步长 `grid_step + (count-1)*grid_step_add`，手数 `initial_lot * lot_mult^count` 归一化且不小于上一层，15 秒时间防抖，同层 1 秒防重入 | P0 |
| FR-STR-05 | 整组止盈：抛物线目标利润；安全垫 ≥ 35 点启用 25 点固定回撤移动锁利，< 35 点达到 100% 目标即市价秒平（AGENTS §9） | P0 |
| FR-STR-06 | 账户级锁仓：总浮亏 ≤ -`lock_trigger_usd` 触发 IDLE→ARMING→LOCKED 三态机；按净敞口打一张反向单；两档滑点重试；LOCKED 下人工平仓不补锁；满 2 小时自动全平（点差 ≤ 0.80 门禁）；持仓归零 30 秒后复位 | P0 |
| FR-STR-07 | 开仓门禁（首单）：锁仓态、暂停、交易时段边界（开市后 30 分 / 短休市前 30 分 / 长休市前 4 小时）、点差 ≤ 0.50、日历可用、新闻窗口（事件前 60 分钟、后 180 分钟）、2 秒冷却 | P0 |
| FR-STR-08 | 加仓门禁：锁仓态、暂停、长休市前 4 小时、点差。**新闻避险不拦加仓**（AGENTS §8 方案 A） | P0 |
| FR-STR-09 | 平仓重试：篮子平仓失败 200ms 重试，连续 5 次后降频 10 秒并告警；全平时先平网格腿后平锁仓腿 | P0 |
| FR-STR-10 | 美分账户（USC）所有金额参数直接按账户币种单位使用，不做换算（AGENTS §4、§7） | P0 |
| FR-STR-11 | 隔夜利息按 Swap-Free 处理：浮盈亏计算包含 API 返回的 `swap` 字段但不做任何预估或预警 | P0 |

### 4.5 手动操作（OPS）
对应 EA Q 键快捷菜单七个动作，全部需二次确认。

| 编号 | 动作 | 行为 |
| --- | --- | --- |
| FR-OPS-01 | 一键锁仓 | 净额中性化并进入冻结（等价 `ManualLock`） |
| FR-OPS-02 | 一键平仓 | 平掉本账户台账内全部持仓（紧急模式，两阶段） |
| FR-OPS-03 | 一键平亏 | 平掉浮亏持仓 |
| FR-OPS-04 | 一键平盈 | 平掉浮盈持仓 |
| FR-OPS-05 | 一键平多 / 一键平空 | 平掉指定方向篮子 |
| FR-OPS-06 | 暂停 / 恢复开仓 | 只平不开；状态持久化，重启保持 |
| FR-OPS-07 | 收编外部持仓 | 将外部持仓登记为网格 / 锁仓角色（管理员） |

## 6. 约束与既定设计（不可变更）

来自 `AGENTS.md`，在本项目中同样生效：

1. 币种：原生支持 USD 与 USC，不得拒绝 USC。
2. Swap-Free：风险分析不计隔夜费。
3. 千元阶梯告警：USD / USC 统一数值，不缩放，不是 Bug。
4. 方案 A：新闻避险只拦首单，不拦加仓；事件期不自动强平存量网格。
5. 分层止盈：安全垫 < 35 点时禁止移动锁利，达标秒平。
